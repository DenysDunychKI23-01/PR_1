# Практична робота: Практичне використання методів масивів у JavaScript

Цей проєкт містить рішення практичних завдань із мови JavaScript, присвячених використанню вбудованих методів обробки масивів об'єктів.

## 🛠 Технології
* HTML5
* JavaScript (ES6+)
* GitHub Pages

---

## 📋 Опис завдань та використані методи

1. **Фільтрація та пошук у масиві об'єктів**
   * Використані методи: `filter()`, `find()`[cite: 13].
   * Реалізовано функції для фільтрації товарів за наявністю на складі (`inStock > 0`) та пошуку товару за назвою[cite: 13].

2. **Групування та сортування масиву об'єктів**
   * Використані методи: `reduce()`, `push()`, `sort()`[cite: 13].
   * Створено функцію `groupBy` для групування студентів за навчальними групами та функцію `sortStudentsByGrade` для сортування за оцінками у порядку спадання[cite: 13].

3. **Статистичний аналіз даних з масиву об'єктів**
   * Використаний метод: `reduce()`[cite: 13].
   * Здійснено розрахунок середньої зарплати працівників та пошук працівника з найбільшим досвідом роботи[cite: 13].

4. **Обробка та аналіз даних про книги**
   * Використані методи: `reduce()`, `sort()`, `filter()`, `map()`[cite: 13].
   * Вибірка непрочитаних книг, сортування книг за автором і роком видання, а також фільтрація топ-книг за рейтингом[cite: 13].

5. **Фільтрація та маніпуляція вкладених об'єктів у масиві**
   * Використані методи: `reduce()`, `filter()`[cite: 13].
   * Обчислення загальної суми коштів, витрачених конкретним клієнтом на основі вкладених структур замовлень[cite: 13].

6. **Об'єднання та оптимізація даних у масиві об'єктів**
   * Використані методи: `reduce()`, `find()`[cite: 13].
   * Інтеграція даних між масивами товарів та покупок для розрахунку загального доходу від продажу кожного товару[cite: 13].
